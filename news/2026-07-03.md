## 🔥 The Big Stories

**Alibaba Bans Claude Code Over Alleged Backdoor Concerns**

[Reuters is reporting](https://www.reuters.com/world/china/alibaba-ban-claude-code-workplace-over-alleged-backdoor-risks-source-says-2026-07-03/) that Alibaba has moved to ban Claude Code internally, citing alleged backdoor risks, according to a source familiar with the matter. The ban affects employee use across the company.

This is notable on multiple levels. Claude Code has been one of the fastest-adopted AI coding tools globally — and a major revenue driver for Anthropic. A formal ban from one of China's largest tech employers signals the geopolitical fault lines around AI tooling are sharpening. Whether the backdoor claim has technical merit or is primarily a political/competitive rationale remains unclear, but either way the signal is loud.

Watch for: Whether other Chinese firms follow Alibaba's lead, and how Anthropic responds publicly. This could accelerate a bifurcation where Chinese enterprises default to domestic tools (Tongyi, Doubao, Kimi) for anything code-adjacent.

* * *

**A 6-Page Paper Just Broke the "Best Model" Debate**

A paper making rounds this morning ([flagged by @ArchiveExplorer](https://x.com/ArchiveExplorer/status/2073004382187110510)) found that running the same model — Claude Opus 4.6 — across 9 different harnesses produced a **22-point spread on the same benchmark**. Same model. Different scaffolding. Wildly different results.

The implication is uncomfortable: almost every leaderboard comparison you've read is measuring the harness as much as the model. This matters enormously for anyone making purchasing or build decisions based on benchmark data. The "best model for coding" might just be the model that got the best eval wrapper.

This also connects to the ongoing [EdgeBench work](https://x.com/tszzl/status/2072816780343738549) on long-horizon agent runs — the environment around the model increasingly _is_ the product.
