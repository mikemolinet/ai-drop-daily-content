# AI News Drop — Wednesday, July 1, 2026

Anthropic is having a day. New model, export controls lifted, and a steganography scandal — all before lunch.

* * *

### 🔥 The Big Stories

**Claude Sonnet 5 Drops — But the New Tokenizer Will Cost You**

Anthropic [launched Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5) today, and it's already the #2 story on Hacker News with 1,162 points. The model is available to free users too, which is notable — Anthropic is clearly playing for mindshare, not just revenue. But read the fine print: Simon Willison [clocked](https://x.com/simonw/status/2072068898648949184) that the new tokenizer makes Sonnet 5 roughly **1.4x more expensive for English** and 1.33x more expensive for Spanish compared to prior models. Mandarin users are mostly unaffected. If you're building English-heavy apps, do the math before you migrate. The HN thread (697 comments) is a goldmine for early real-world evals.

**Claude's Export Controls Just Got Lifted**

The Department of Commerce has [lifted export controls on Claude Fable 5 and Mythos 5](https://twitter.com/AnthropicAI/status/2072106151890809341), and Anthropic says Fable 5 will be available globally again tomorrow. This story hit 751 points on Hacker News and 27K+ engagements via Simon Willison's retweet — which tells you how big a deal restricted model access had become. The geopolitical wrapper on frontier AI is real: export controls on _software models_ are now a standard policy lever. What to watch: whether Mythos 5 follows the same timeline, and how this reshapes Anthropic's international enterprise deals.

**Claude Code Is Quietly Fingerprinting Its Requests**

This one's the most interesting story of the day. A [Hacker News post at 2,176 points](https://thereallo.dev/blog/claude-code-prompt-steganography) (629 comments) reports that Claude Code is steganographically embedding information — timezone, proxy data, possible AI lab affiliations — into system prompts in ways users can't detect. Anthropic has apparently confirmed it. Security researcher @Hesamation noted the obvious double standard: if a Chinese AI lab did this to American users, it would be a congressional hearing. Anthropic says this has been addressed, but the damage to trust is real. If you're deploying Claude Code in enterprise environments, audit your system prompt handling. Now.

### 💡 Builder's Corner

**Shot-Scraper Now Records Videos.** Simon Willison [added video support](https://x.com/simonw/status/2072001270978855074) to his \`shot-scraper\` browser automation tool. You write a YAML storyboard, and it records a video demo of your web app. He even used Codex Desktop + GPT-5.5 to generate the storyboard. Genuinely useful for teams that need to auto-document feature releases without recording manually.

**Goose Runs Fully Offline on Android.** [@HowDevelop got](https://x.com/HowDevelop/status/2072286696323137961) the open-source Goose agent running completely offline on Android — no cloud, no laptop, using a local llama.cpp runtime with a Gemma 4 GGUF model. Edge AI agents are no longer theoretical. If you're building for privacy-sensitive use cases or low-connectivity markets, this stack is worth a close look.
