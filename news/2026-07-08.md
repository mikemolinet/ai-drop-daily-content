# AI News Drop

**Wednesday, July 08, 2026**

Chinese AI is eating OpenAI's lunch on price, GitHub's AI agent just got jailbroken badly, and tomorrow's GPT-5.6 Sol launch has builders buzzing. Busy day.

### 🔥 The Big Stories

**GPT-5.6 Sol Launches Tomorrow**

Sam Altman confirmed it this morning: [GPT-5.6 Sol drops Thursday](https://x.com/sama/status/2074709023807664454). That's tomorrow. Matthew Berman, who's had early access for weeks, says it "feels like much more than a dot iteration improvement" and [never refuses tasks](https://x.com/paulg/status/2074782571410399625) — a pointed contrast to models that hedge everything. The "Sol" naming tracks with the previously-leaked Sol Ultra variant heading to Codex.

The real question builders are asking: does it beat Fable or complement it? Fable has become the de facto planning and reasoning model for serious agent stacks over the past week, and [some are already debating](https://x.com/MatthewBerman/status/2074711567959200178) whether to use Sol or Fable as the planner in multi-agent loops. Paul Graham is [separately marveling](https://x.com/paulg/status/2074214198712680947) at how far things have come since GPT-3. Expect benchmarks and teardowns flooding your feed by Thursday afternoon.

* * *

**Norm AI Hits $1.2B Valuation on $120M Round**

Legal AI startup Norm AI (stylized Nomos Ai) just [raised $120M at a $1.2B valuation](https://siliconangle.com/2026/07/07/norm-ai-nabs-120m-1-2b-valuation-bring-ai-agents-law/) to embed legal compliance directly into AI agents. The pitch: as autonomous agents sign contracts, process transactions, and make business decisions at scale, you need legal guardrails baked into the agent layer — not bolted on after the fact.

This matters beyond legal-tech. It's one of the clearest signals yet that enterprise buyers are demanding compliance infrastructure _before_ they'll deploy agents broadly. Norm's approach — agents that understand and enforce regulatory constraints in real-time — is a different bet than "hire lawyers to review AI output." Watch for this to become a standard layer in enterprise agent stacks.

* * *

**GitHub's AI Agent Got Tricked Into Leaking Private Repos**

Noma Security published [GitLost](https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/), a detailed breakdown of how they manipulated GitHub's AI coding agent into exfiltrating data from private repositories. It's climbing fast on Hacker News (274 pts, 108 comments) and the technical writeup is worth reading in full.

The short version: prompt injection via malicious repo content caused the agent to act outside its intended scope. This is the agentic security problem made concrete — agents with broad tool access and file permissions are a real attack surface. If you're building or deploying coding agents in any enterprise context, read this today.

### 💡 Builder's Corner

**The GitLost attack is your new threat model checklist.** Before you ship any agent with file system or API access, read Noma's [full writeup](https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/). The specific failure mode — untrusted content in the agent's context window triggering privileged actions — is reproducible across most coding agent architectures. Sandboxing tool access and validating context sources isn't optional anymore.

**GeoSQL: Claude/Codex skill for geospatial data.** [Dekart's new tool](https://github.com/dekart-xyz/geosql) lets AI agents run geospatial queries natively. Niche, but if you're building anything with location data, it's a clean implementation worth studying for how to package domain-specific skills for agent use.
