The AI toolkit war is heating up with OpenAI making aggressive moves to steal developer mindshare while Microsoft hunts for the next breakthrough.

### 🔥 The Big Stories

**OpenAI Goes Full Sales Mode with Free Codex Migration**

Sam Altman announced that OpenAI is offering companies [two free months of Codex usage](https://x.com/sama/status/2054626219858293128) for the next 30 days to encourage switching from competitors. This is OpenAI's most direct enterprise sales play yet, targeting GitHub Copilot and other coding assistants with what Altman calls "the best AI coding product." The timing suggests OpenAI is feeling pressure from Anthropic's growing developer adoption and wants to lock in enterprise relationships before competitors catch up.

**Microsoft Reportedly Eyeing Inception AI Acquisition**

Microsoft is [exploring a deal to acquire Inception](https://x.com/testingcatalog/status/2054863887200047340), the AI lab behind Mercury 2 — the first reasoning diffusion LLM. If this goes through, it would give Microsoft a significant edge in next-generation AI architectures that combine reasoning with diffusion models. Inception's breakthrough could eventually power everything from Copilot to Azure AI services, marking Microsoft's continued push to stay ahead in the foundation model race.

**Real AI Production Data Reveals Surprising Market Dynamics**

Vercel's AI Gateway data shows [Google dominating production scale while Anthropic leads in coding spend](https://x.com/rauchg/status/2054671803264757957), with OpenAI growing fast since the 5.4 release. This real-world usage data contradicts a lot of the narrative around model preferences and shows the market is "more fluid" than it appears from the outside. For builders, it suggests betting on any single provider long-term might be risky.

### 📡 Quick Hits

**Claude User Recovers Lost Bitcoin with AI Help** — A Bitcoin investor [used Claude to locate and recover previously lost private keys](https://x.com/APompliano/status/2054896843574722873), finding a local file with the wallet data. While amazing for this user, it highlights serious security implications if bad actors start using AI for similar key recovery attacks.

**AI Capability Assessments Show Post-Exponential Growth** — Independent assessments from METR and the UK's AISA suggest [we're past the early exponential phase](https://x.com/emollick/status/2054781154553729088) of AI capability growth, moving into "super-exponential" territory according to Ethan Mollick's analysis.

**Anthropic Reveals 90% of Internal Code Written by Claude** — In a recent conversation, Anthropic disclosed that [over 90% of code inside the company is now written by Claude Code](https://x.com/patrick_oshag/status/2054742528302215386), with their NDR over 500% on an annualized basis. The company's first revenue dollar came in March 2023.

**Agent Skills Marketplace Launches with 1M+ Skills** — A new [AI agent skills marketplace](https://x.com/cyrilXBT/status/2054877213716296014) went live with over one million production-ready skills and plugins. Unlike prompt libraries, these are installable skills that agents can use permanently across different tasks.
