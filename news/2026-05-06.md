The layoffs-plus-AI playbook is becoming Silicon Valley's new normal, with Coinbase leading the charge on radical team downsizing.

### 🔥 The Big Stories

**Coinbase Experiments with Single-Person Teams Backed by AI Agents**

[Coinbase is testing 1-person teams combined with AI agents](https://x.com/gregisenberg/status/2051683558486392890) while announcing 700 layoffs, part of a broader trend reshaping how tech companies think about headcount. The crypto exchange joins Shopify (which now requires proof that AI can't do a job before new hires) and Block (cutting ~4,000 roles, roughly 40% of staff) in betting that AI can replace entire departments.

This isn't just cost-cutting—it's structural transformation. When a major public company starts testing whether one person plus AI agents can do the work of entire teams, it signals a fundamental shift in how work gets organized. The question isn't whether this spreads to other companies, but how fast.

**Sam Altman Says OpenAI's New "Instant Model" Feels "Switched On"**

OpenAI CEO Sam Altman is hyping the company's latest model release, calling the [new instant model in ChatGPT "so good"](https://x.com/sama/status/2051758152224506203) and noting that [ChatGPT feels very "switched on" now](https://x.com/sama/status/2051829422265979047). He's also praising [GPT-5.5 Codex for non-coding tasks](https://x.com/sama/status/2051783339502375418), saying he keeps being "pleasantly surprised" by capabilities he didn't expect.

The CEO enthusiasm tour suggests OpenAI has made meaningful improvements to model responsiveness and general reasoning. Developer teams are already reporting [significant GPT-5.5 usage spikes](https://x.com/thdxr/status/2051874553152807111) based on spending data, indicating the performance gains are translating to real adoption.

### 📡 Quick Hits

**Claude Opus 4.7 Performs Worse Than 4.6 on Key Benchmarks** — [BridgeBench data shows](https://x.com/bridgebench/status/2051989645605372101) the newer Claude Opus 4.7 scoring 78.4 on UI design tasks versus 4.6's 81.1. Anthropic released a regression, with the older model now ranked #2 while the newer sits at #5. Even Claude Sonnet 4.6 beats both Opus versions.

**Tower 16 Git Client Ships with AI Commit Messages** — The Mac git client [now includes AI-powered commit message generation](https://x.com/AlternativeTo/status/2051973512576033201) via Claude Code and OpenAI Codex integration, plus a redesigned working copy view and performance improvements.

**Developer Tools Missing the Agent Opportunity** — [Anthropic's Zara Zhang notes](https://x.com/zarazhangrui/status/2051900943831335167) that many developer tools are now useful to anyone with agent access, not just professional developers, but their messaging still intimidates normal users instead of expanding their market.

**Google Passes Nvidia as World's Most Valuable Company** — Google hit almost $5 trillion in market cap, up 130% since last year's I/O conference, driven by cloud revenue hitting $20B quarterly (up 63%) and AI solutions growing 800%.

### 💡 Builder's Corner

**Agents Can Now Create Cloudflare Accounts and Deploy Apps** — [Cloudflare launched agent-friendly infrastructure](https://blog.cloudflare.com/agents-stripe-projects/) allowing AI agents to autonomously create accounts, buy domains, and deploy applications. This removes a major friction point for autonomous deployment workflows.

**Computer Use Costs 45x More Than Structured APIs** — New analysis shows that [using AI for computer automation is dramatically more expensive](https://reflex.dev/blog/computer-use-is-45x-more-expensive-than-structured-apis/) than structured API calls. If you're building agent workflows, prioritize API integrations over screen automation wherever possible.
