**OpenAI Ships GPT-Realtime-2 as Voice AI Takes Center Stage**

The race for natural conversation is heating up as generational preferences split the AI interface landscape.

### 🔥 The Big Stories

**OpenAI Quietly Drops GPT-Realtime-2**

OpenAI [shipped a new speech-to-speech model](https://x.com/RayFernando1337/status/2052721389732589654) yesterday with GPT-Realtime-2, marking the first speech-to-speech model "good enough to use in production," according to early reports. The timing feels deliberate — Sam Altman noted that [young people prefer voice interfaces while older users stick to text](https://x.com/sama/status/2052462428663992564). Japanese developers are already building real-time conversational apps with virtual characters. This isn't just about convenience; it's about AI becoming truly conversational rather than transactional.

**Codex Now Works in Chrome**

OpenAI's [Codex integration with Chrome](https://x.com/sama/status/2052482715010949288) on macOS and Windows went live, bringing AI coding assistance directly into browsers. The move signals OpenAI's push beyond IDEs into everyday web workflows. For developers juggling documentation, Stack Overflow, and coding environments, having Codex context-aware of browser tabs could streamline the constant alt-tab dance. Worth watching: how this affects VS Code extensions and whether other browsers follow suit.

**Kalshi Hits $22B Valuation on $1B Raise**

Prediction market platform [Kalshi closed a massive $1B round at $22B valuation](https://x.com/a16z/status/2052404488129151444), led by Coatue with participation from Morgan Stanley, Sequoia, and a16z. While not directly AI, prediction markets are becoming crucial infrastructure for AI decision-making and training. The validation suggests institutional appetite for platforms where AI agents might eventually trade predictions autonomously.

### 📡 Quick Hits

**Real-time Translation API Launches**: A new [real-time translation model hit API](https://x.com/yoheinakajima/status/2052500373148184976) yesterday, with Japanese developers already testing conversational applications.

**Claude Outage Hits Developers**: [Claude experienced downtime](https://x.com/mattshumer_/status/2052047684291252230) yesterday, reminding builders why API redundancy matters for production AI apps.

**Benchmark Reproducibility Crisis**: [Most LLM benchmark scores can't be reproduced](https://x.com/abxxai/status/2052706178040463476) by third parties due to prompt drift and missing sampling parameters — a growing credibility problem for model evaluation.

**Apple Quietly Kills High-Memory Macs**: Apple [discontinued 512GB and 256GB Mac Studio models](https://x.com/TheGeorgePu/status/2052507623845511181), leaving 96GB as the max. For developers running local LLMs, this feels like deliberate limitation pushing users toward cloud AI services.

### 💡 Builder's Corner

**Claude Opus Token Burning**: One developer discovered their [Claude Code settings were burning 8-15M Opus tokens monthly](https://x.com/tomcrawshaw01/status/2052377542548746615) due to \`alwaysThinkingEnabled: true\` running deep reasoning on simple tasks like "rename this variable." Check your thinking budget allocation — 20-40% waste on trivial prompts adds up fast.

**New CLI Factory for Agent APIs**: The [Printing Press CLI-factory](https://x.com/yoheinakajima/status/2052501886494978297) launched to address the reality that "most APIs suck for agents." Built as both library and factory for creating agent-friendly interfaces.
